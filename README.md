# Chazman Mods for Valheim

Runic mods for building, crafting, storage, exploration and server administration, created by Charles Sammons (Chazman).

## Downloads

[Download the latest release](https://github.com/ChazmanMods/ValheimMods/releases/tag/runic-2026-09-24) · [Browse Thunderstore](https://thunderstore.io/c/valheim/p/Chazman/)

The September 24 release contains 22 mods and three suites. Choose individual mods or use a suite for your administrator, player or dedicated-server profile. Suite packages install their dependencies through a mod manager. For manual installation, install the dependencies listed in each mod's manifest.

## What is new

- Per-mod language files with English fallback.
- Sentinel's updated People, Players, Commands and content catalog panels.
- Integrated administrator commands, status-effect durations, aliases, bindings and command chains.
- Gameplay updates across crafting, storage, production, portals and WaterGardens.

Install RunicSentinel on administrator clients, RunicSentinelServer on dedicated servers, and RunicSentinelClient on ordinary player clients. Install the same WaterGardens version on participating clients and servers.

Read each mod's README and changelog for its controls and configuration. [BUILDING.md](./BUILDING.md) describes source builds. [The release catalog](./docs/RELEASE-CATALOG.json) records package versions and SHA-256 hashes.
