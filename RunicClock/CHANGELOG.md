# Changelog

## 1.0.1

## 1.0.0

- Added a client-only HUD clock with 12/24-hour game time, world day, and sun/moon indicator.
- Added an optional local real-world clock with an independent time-format setting.
- Added configurable placement, scale, background opacity, menu visibility, and a Left Alt+C visibility shortcut.
- Automatically hides with the game HUD and during loading; does not alter gameplay or saves.
