# Changelog

## 2.0.9 - 2026-09-30

- Align Precision, the piece description, and Target in one horizontal row to lower the top of the panel.
- Keep Precision and Target at the same fitted font size, with axis hints beneath Precision when shown.
- Fit the panel within the screen width and restore its original dimensions when hidden.
- Retain StartupAccelerator compatibility and language-file support from 2.0.8.

## 2.0.8 - 2026-09-24

- Fixed compatibility with StartupAccelerator so precision building activates correctly when both mods are installed.
- Retained the F4 Local/World rotation toggle and language-file support.

## 2.0.7

- Added language files that follow Valheim's selected language, with English fallback and no additional plugin required.

## 2.0.6 - 2026-09-16

- Added a saved F4 toggle between Local and World rotation axes. Press once to switch; no holding or modifier keys required.
- Switching modes leaves the piece in place and keeps movement settings independent.
- Updated the HUD and axis guides to show the selected rotation mode.
- Added instructions for matching and bending beams into arches.

## 2.0.5

- Improved horizontal rotation of tilted pieces and updated the yaw guide.

## 2.0.4 - 2026-09-11

- Updated compatibility for Valheim 1.0.12.

## 2.0.3 - 2026-09-09

- Updated build categories, piece selection, placement, and area repair for Valheim 1.0.

## 2.0.2 - 2026-09-05

- Updated the package description and building guide.

## 2.0.1 - 2026-08-29

- Made the mod independently installable with BepInEx as its only dependency.
- Improved undo and area repair for solo and multiplayer building.
- Added piece-local rotation and guides that follow the piece.
- Restricted precision mode to Hammer building.
- Made F6 cycle all unlocked pieces when the search query is empty.

## 2.0.0

- Introduced six-axis building controls, matching, repeat placement, precise readouts, and axis guides.
