# Runic Storage 2.4.0

Organize your base with shared chest access, Quick Stack rules, SmartSort, chest labels, restocking, search, and stack consolidation.

## Controls

| Action | Default control |
|---|---|
| SmartSort preview and confirmation | Left Alt + O |
| Quick Stack one carried stack | Ctrl + Shift + left-click |
| Quick Stack All | Left Alt + Q |
| Restock | Left Alt + R |
| Search | Left Alt + F |
| Sort open chest | Left Alt + S |
| Sort personal inventory | Shift + Ctrl + P |
| Store All | Left Alt + A |
| Consolidate carried stacks | Left Alt + C |
| Select carried items for trash | Shift + Alt + right-click |

Repeat the SmartSort shortcut within 30 seconds to confirm its preview. Configure chest rules and colored labels to organize supplies by item and biome.

Inventory sorting leaves protected items and slots fixed, including configured hotbar protection, locked and equipped items, quest items, and supported equipment/quick-slot rows.

Runic reads the current dimensions of expanded or resized standard chests and works with their live inventories.

Configure settings in `BepInEx/config/chazman.RunicStorage.cfg`.

## Installation

Install matching 2.4.0 versions on the server and participating clients. Each Runic module is independently installable. Keep existing configurations and RunicOperations data when updating.

## Languages and support

The mod follows Valheim's selected language. Keep the included `Translations` folder beside the DLL when installing manually.
