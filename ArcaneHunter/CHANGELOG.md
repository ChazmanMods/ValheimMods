# Changelog

## 0.2.0

- Added automatic pickup of loaded loose items within 500 meters by default; configurable from 2 to 2,000 meters.
- Pickup works during free-camera use and transfers items directly to inventory.
- Preserved vanilla pickup toggle, capacity, weight, tar, placed-item, unique-item and network ownership checks. Scans run in bounded batches four times per second.
- New settings synchronize from the host. Update clients and server together.

## 0.1.0

- Introduced ArcaneHunter with an ArcaneDecor-style oval hunting medallion icon.
- Included a practical player guide with a first-hunt walkthrough, progression tables and spawn configuration examples.
- Added individual ambient spawn controls for 39 creatures and custom-prefab overrides.
- Added Hunter's Sense, species focus, aging tracking clues, and wind bearings.
- Added character-persistent journals, species mastery, renown titles, daily oaths, and eight achievement seals.
- Added host-synchronized gameplay configuration and network-owner kill receipts.
- Initial test release; in-game and multiplayer validation remains pending.
