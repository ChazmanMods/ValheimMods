# RunicDeathPenalty icon

Created September 14, 2026 with the built-in image generation tool, using RunicCore/icon.png as the medallion/material reference and RunicSafety/icon.png as the funerary atmosphere reference.

The new subject is a skull carved into a Nordic gravestone, a broken cyan protective halo, and a restrained amber crack representing the cost of death. The complete wood-and-iron outer rim and black background follow the Runic family.

- `icon-deathpenalty-master.png`: original full-resolution generated artwork.
- `icon-deathpenalty.png`: 256x256 package asset, mechanically downsampled from the master.
- `icon.png`: preserved original borrowed placeholder; no longer selected by Build-RunicDeathPenalty.ps1.

The package builder installs the new 256x256 asset as `icon.png` at the archive root. No gameplay code changes accompany this artwork.
