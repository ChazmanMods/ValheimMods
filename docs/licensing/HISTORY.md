# Licensing history

The repository changed to the Chazman Mods Source-Available License after
commit `d6ccdfa` on September 14, 2026. The current policy permits inspection;
reuse of newly licensed original code requires written permission. It is not
an open-source license.

## Earlier MIT publication

- Commit `e8908b55cddb3586e1d23183f6f824708945e25e` introduced MIT licensing.
- Commit `d6ccdfa` published the synchronized Runic sources under that license.
- Release tag `runic-2026-09-14` points to that MIT-era source snapshot. Its
  original packages and MIT LICENSE asset remain a historical release.
- [The previous MIT text](./PREVIOUS-MIT-LICENSE.txt) is retained as a record of
  that grant, not as a license for newly added code covered only by the current
  source-available terms.

Changing the current license does not withdraw existing MIT permissions. The
previously licensed code remains available under MIT, including through Git
history and that release. These restrictions cannot stop permitted reuse of
that earlier code. They apply to new original material released only under the
new terms, subject to any other applicable rights.

Third-party licenses remain unchanged. In particular, preserve the MIT license
and upstream attribution supplied with RunicCharacterVault and any other
component-specific notices. The project does not relicense Valheim or Unity.

## Future distributions

Include the current LICENSE and applicable third-party notices with future
packages. State the license applicable to the particular release instead of
calling all versions MIT licensed or all versions restricted. Do not replace
historical packages or rewrite Git history to suggest earlier grants vanished.
