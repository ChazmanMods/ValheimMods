# Runic Mod Suite 1.2.51

The full Runic collection for a player who hosts and plays, including the Sentinel administrator dashboard.

## Installation

Choose the suite for your role in your mod manager. It installs the packages listed below and their dependencies.

| Profile | Suite |
|---|---|
| Dedicated server | Runic Mod Server Suite |
| Player joining a server | Runic Mod Client Suite |
| Player hosting and playing | Runic Mod Suite |
| Remote administrator | Client Suite plus full RunicSentinel |

Update the host and participating clients together, then restart. Keep existing world, character, configuration and RunicOperations folders when updating. Use a single server-character mod and use RunicSigns in place of BetterSigns.

Use either full Sentinel or SentinelServer in a host profile. Hosts using Sentinel's building and terrain controls use full Sentinel. The individual Runic mods can also be installed separately.
